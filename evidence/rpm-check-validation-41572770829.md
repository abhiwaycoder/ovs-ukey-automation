## Runtime-validation boundary

This workflow validates the RPM build and the OVS userspace `%check` suite.
It does not run the separate real-datapath runtime reproduction, does not
enable kernel datapath tests, and does not validate OpenStack deployment.

Three manual runtime cleanup cycles were validated separately using the
EL8.10-built OVS userspace against a RHEL 9.8 host kernel in an isolated
container network namespace. The evidence is maintained in
[validation/ovs-2.17.8-stale-ukey-runtime-validation/](../validation/ovs-2.17.8-stale-ukey-runtime-validation).
That manual test is not native EL8 kernel validation and does not
independently measure the four-missed-dump threshold.
